Why this works

Built on the evidence base for adult professional-exam prep

This tool mirrors the actual FMF PQS structure - 12 fundamentals sections (101–112), a written exam, and an oral board that is ⅓ rote memory and ⅔ open-ended discussion, each requiring an 80% pass. The three modes below map to the strongest evidence in learning science for exactly that structure: retrieval practice with spaced repetition for rote content (flashcards), interleaved applied practice for judgment/discussion content (Applied Discussion), and simulation-based mastery learning for the board itself (Murder Board) - repeat attempts against a fixed 80% standard, the same model used in medical education board prep.

    Murder Board

    Military slang for exactly this: a deliberately brutal practice board meant to prepare you for the real thing. A mix of ⅓ rote-memory and ⅔ open-ended questions, scored to the same 80% standard used by the actual FMFWO/FMFQO board. This is deliberate practice - take it repeatedly, closing gaps each round, rather than once.
